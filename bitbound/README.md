# BITBOUND — Pocket Quest

A mobile-friendly 8-bit fantasy adventure built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Controls

- Explore tab: move with WASD or arrow keys when the world is focused.
- Use the on-screen directional buttons on mobile.
- Move near NPCs, gates, or hidden landmarks and press **INTERACT**.
- MAP, QUESTS, FIGHT, STATS, and BAG remain separate screens.

## Project structure

- `index.html` — game interface and navigation
- `style.css` — pixel-art visual styling
- `game.js` — regions, combat, progression, quests, inventory, and exploration

Player progress is stored locally in the browser with `localStorage`.
